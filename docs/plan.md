# 《猪栏菜：时序奖学金》浏览器版原型方案

## 目标

将当前“规则验证原型”替换为可扫码访问的、**以舞台画面为第一视觉层**的浏览器养成游戏。游戏不能以通用仪表盘为主，而应以校园背景、角色立绘、时间轨道、行动卡、ADV 对话与年度考核构成连续的游戏体验。

## 技术方案

- **纯静态前端**：HTML、CSS、原生 ES Module JavaScript；宝塔/Nginx 可直接部署，无服务器依赖。
- **主舞台**：16:9 固定视觉舞台，自适应缩放到手机横屏和桌面浏览器。
- **资源**：原创生成的校园背景和角色占位立绘放在 `public/assets/`。所有资源路径集中在 `src/main.js` 顶部，后续替换不影响交互逻辑。
- **状态**：前端状态和本地存档由 `localStorage` 管理；日后可改接服务端排行榜或云存档。

## 视觉方向

- **设计运动**：明亮的校园视觉小说舞台叠加养成游戏 HUD，不复刻任何既有作品的具体角色、图片、UI 素材或文案。
- **核心原则**：场景优先、状态可读、行动有节奏、每个玩法界面有不同构图。
- **色彩逻辑**：象牙白承载纸质档案；雾紫表达时序异常；青绿表现稳定与休息；金色强调奖学金门槛；珊瑚色提示风险。
- **布局**：背景、时间环、角色、信息轨、功能浮层由后至前分层；养成信息从中央卡片群进入，ADV 信息落到下方对白框。
- **动效**：时间环缓慢旋转、行动卡轻浮、角色进场、对白逐字出现、选择卡悬停上移。
- **品牌表达**：一句话定位为“把大学四年养成一次时序校准”。气质是明亮、荒诞、认真。

## 界面状态

| 状态 | 主要元素 | 交互 |
|---|---|---|
| 养成 | 8 次行动轨、状态表、6 张行动卡、角色立绘 | 选择行动并结算数值 |
| ADV | 校园舞台、角色、姓名条、对白框、2 个选择 | 选择影响好感与稳定度 |
| 答题 | 三个评委印记、题目卡、策略选择 | 增减评委注意力 |
| 年审 | 奖学金审查单、门槛、通过印章 | 展示本年是否幸存 |
